# 권태근 포트폴리오

토목산업기사 필기 합격과 실무 결과물 세 가지를 한 장에 정리한 포트폴리오입니다.

**보기: https://kwontaegeun.vercel.app**

## 담긴 내용
- **자격**: 토목산업기사(필기 합격 · 실기 응시 완료 · 최종 발표 2026.12.18), AI 윤리 과정 수료(Coursera · UNESCO × LG AI Research)
- **스파게티 교량, 설계에서 시공 순서까지**: 처음 3D 설계와 Claude와 함께 짠 18단계 시공 순서 시뮬레이션
- **청계천복개(좌안) 정밀안전진단 보고서 분석**
- **현대건설 10년 재무제표 분석과 자동 대시보드**

## 파일
```
index.html   포트폴리오 페이지(한 파일)
img/         페이지에 쓰인 그림 6장
```

결과물 페이지(시공 순서 시뮬레이션, 3D 설계, 대시보드, 보고서 PDF)는 [KTG_Hyundai](https://github.com/HSC-Class01/KTG_Hyundai) 저장소에 있고, 포트폴리오의 버튼이 그 주소로 연결됩니다.
